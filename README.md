# 🐜 Ant OS

Мобильная операционная система на Python + Kivy.

## Возможности

- 📱 Полноценный интерфейс (рабочий стол, dock, навигация)
- 🛡️ AntGuard — встроенный антивирус
- 🔋 Реальная батарея (Android BatteryManager)
- 📄 HtmlSupport — парсер HTML, CSS, JavaScript
- 📦 Магазин приложений Ant Market
- 🎵 Музыка, 📷 Камера, 🖼️ Галерея
- 🌐 Браузер, 📨 SMS, ⏰ Часы
- 🎨 Обои, иконки, звуки
